# Privacy Policy

This plugin processes image files supplied by the Dify workflow for the sole purpose of decoding barcode data.

- It does not require an API key.
- It does not intentionally send uploaded images to an external barcode service.
- It does not intentionally persist uploaded images or decoded barcode values outside the Dify plugin execution context.
- It uses the bundled Python dependencies only for local image decoding.

Users remain responsible for the data handling and retention policies of their Dify environment and any downstream tools such as databases.
